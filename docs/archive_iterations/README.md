# Development Iteration Archive

This directory contains development iteration records documenting the step-by-step evolution of the Boat framework.

## Structure

- `it_*.txt` / `it*_*.txt` — Main framework iterations
- `mnist/` — MNIST example-specific iterations
- `safetensors/` — Safetensors format implementation iterations

These records are preserved for reference and are not required for building or using the framework.
